# Tech Superpower Portfolio 🚀

This is my submission for the **AWS Student Builder Challenge**. 

## 🛠️ The Superpower: Root Access Terminal
Instead of a standard portfolio, I built a fully interactive **Developer Terminal**. Visitors can explore my background, skills, and projects using a CLI interface.

### 🌟 Creative Feature: The Security Breach
The terminal includes a hidden easter egg. By using "administrative" commands like `sudo access` or `override`, the site triggers a visual system glitch and unlocks a hidden **Secret Archive** of my work.

## ☁️ AWS Architecture
- **Hosting**: AWS Amplify Hosting
- **Deployment**: Continuous Deployment via GitHub integration

## 🚀 Quick Start
1. Clone the repo.
2. Open `index.html` in any browser.
3. Type `help` to begin.
